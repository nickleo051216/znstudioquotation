## ✨ 功能特色

### 📊 儀表板
- 總報價單數、成交金額、待確認金額、成交率
- 月度趨勢圖（Recharts）
- 狀態分佈圓餅圖

### 📋 報價單管理
- CRUD 操作（建立/讀取/編輯/刪除）
- 動態新增報價項目
- 自動計算小計 + 稅額 + 總計
- 專案期程里程碑

### 👁️ 報價單預覽
- 專業版面設計（ZN Studio 品牌綠色漸層 header）
- 客戶/報價資訊 + 項目表格 + 付款條件 + 簽章區
- 支援列印 / PDF

### 👥 客戶管理
- 新增/編輯/搜尋客戶
- 建立報價時可直接選擇客戶自動帶入

### ⚙️ 系統設定
- 預設匯款資訊設定
- 備註模板管理（8 組常用備註）
- n8n Webhook URL 顯示
